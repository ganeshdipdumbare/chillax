Install Chillax

Chrome will not install this from a download the way the Web Store does. You load the unzipped folder once. Takes about a minute.

Download the zip, then load the unzipped folder in Chrome. Takes about a minute — Chrome will not install this the way the Web Store does.

Download Chillax (.zip)

Keep this unzipped folder on your computer. If you move or trash it, Chillax turns off. After Chrome restarts, a popup may say “Disable developer mode extensions” — click Cancel to keep Chillax.

  1. 1

    Unzip the file you were sent

    Double-click chillax-for-friends.zip. Keep the folder that contains manifest.json and this page (Downloads is fine).

    manifest.json · install.html Folder
  2. 2

    Open Chrome’s extensions page

    Copy this address, paste it in Chrome’s address bar, and press Enter. Chrome blocks the link from this page.

    chrome://extensions
  3. 3

    Turn on Developer mode

    On the extensions page, find the switch at the top-right and flip it on.

    Developer mode
  4. 4

    Load unpacked

    Click Load unpacked, then choose the unzipped folder with manifest.json — not the zip.

    Load unpacked Load unpacked
  5. 5

    Pin Chillax

    Puzzle-piece icon in Chrome’s toolbar → pin Chillax. You should see the gold-green Cx icon.

    Chillax Pin
  6. 6

    Open the invite link

    Open the YouTube or Netflix link with chillax= in it. Allow the mic; camera stays off until you turn it on.

    …?chillax=ROOM Join

Need an update later? Ask for a new zip, replace the folder contents,Download the zip again, replace the folder contents, then on chrome://extensions click Reload under Chillax.
