Get it in Chrome

Chillax isn’t in the Chrome Web Store yet. Follow along — about a minute — then click Cx and you’re on the couch.

  1. 1

    Unzip the file you were sent

    Double-click __CHILLAX_ZIP__. Keep the folder that pops out — the one with manifest.json and this page. Downloads is a great home.

    manifest.json · install.html Folder
  2. 2

    Paste this in Chrome

    Copy the address, drop it in Chrome’s address bar, and hit Enter. Chrome won’t let us link this page, so this is the one copy-paste.

    chrome://extensions
  3. 3

    Flip on Developer mode

    Top-right of that page, one switch. It sounds serious. It is not. Hard hat optional.

    Developer mode
  4. 4

    Load the folder

    Click Load unpacked, then pick the unzipped folder with manifest.json — the folder, not the zip.

    Load unpacked Load unpacked
  5. 5

    Pin the Cx icon

    Puzzle-piece in Chrome’s toolbar → pin Chillax. That’s your button, wherever Chrome parks it. Click it on a streaming site to open the lounge.

    Chillax Pin
  6. 6

    Click Cx and hop in

    Open a movie — or the invite with chillax= in it. Click the Cx icon, pick a face, and you’re in. Mic and camera stay off until you want them.

    Click Cx on the movie Start
