Install unpacked

  1. 1

    Unzip the file you were sent

    Double-click __CHILLAX_ZIP__. Keep the folder that contains manifest.json and this page (Downloads is fine).

    manifest.json · install.html Folder
  2. 2

    Open Chrome’s extensions page

    Copy this address, paste it in Chrome’s address bar, and press Enter. Chrome blocks the link from this page.

    chrome://extensions
  3. 3

    Turn on Developer mode

    On the extensions page, find the switch at the top-right and flip it on.

    Developer mode
  4. 4

    Load unpacked

    Click Load unpacked, then choose the unzipped folder with manifest.json — not the zip.

    Load unpacked Load unpacked
  5. 5

    Pin Chillax

    Puzzle-piece icon in Chrome’s toolbar → pin Chillax. Click Cx on a supported streaming site to open the lounge. Anywhere else, it asks you to open one first.

    Chillax Pin
  6. 6

    Open the invite link

    Open the invite link with chillax= in it on the same streaming site. Chillax joins the party for you. Mic and camera stay off until you turn them on.
